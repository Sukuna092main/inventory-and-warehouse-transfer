# Ứng dụng Android

**Trạng thái:** Chưa triển khai.

Ứng dụng tiếng Việt có đầy đủ chức năng theo quyền tương đương web, với danh sách và biểu mẫu phù hợp điện thoại. Dùng chung API qua Gateway; bàn giao APK cài trực tiếp, chạy độc lập và kết nối hệ thống local qua mạng nội bộ.

Công nghệ dự kiến: React Native, TypeScript, Expo, Expo Router và React Native Paper. Phạm vi MVP chỉ có Android, không có GPS hoặc giao dịch offline.

Thư mục hiện chỉ giữ chỗ. Khởi tạo ứng dụng và cài dependency khi bắt đầu phần này theo [kế hoạch](../../plan.md).
