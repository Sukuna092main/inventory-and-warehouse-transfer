# Giao diện Web

**Trạng thái:** Chưa triển khai.

Ứng dụng quản trị bằng tiếng Việt, có đầy đủ chức năng theo quyền: tài khoản, người dùng, danh mục, tồn kho, chuyển kho, lịch sử và theo dõi operation. Ưu tiên bảng và bộ lọc; gọi API chung qua Gateway.

Công nghệ dự kiến: React, TypeScript, Vite, React Router và Material UI.

Thư mục hiện chỉ giữ chỗ. Khởi tạo ứng dụng và cài dependency khi bắt đầu phần này theo [kế hoạch](../../plan.md).
